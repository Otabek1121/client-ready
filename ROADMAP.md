# Roadmap

Priorities are proposals, not promises or completed features.

- [x] Single-page mobile/desktop evidence with local HTML + JSON report.
- [x] Bounded same-origin HEAD link checks and explicit unknown states.
- [x] Repeatable deliberately broken local demo and integration tests.
- [ ] More boundary tests: redirects, slow images, malformed pages, resource caps.
- [ ] Configured resource-origin allowlist with clear privacy consequences.
- [ ] Configurable language/theme screenshot matrix without guessing controls.
- [ ] Better stable element locators and grouped duplicate findings.
- [ ] Reproducible sample report + short demo clip after browser verification.
- [ ] GitHub Action wrapper and reviewed, versioned release.
- [ ] First feedback from developers using it on their own sites.

Daily workflow: inspect open changes first; choose one meaningful task; implement and test; open or update one focused draft PR; report the result. Do not stack duplicate PRs or merge without review.
