# Contributing

Start with a reproducible problem. Include Node/OS versions, the command and a minimal local fixture; do not upload private client reports, credentials or tokens.

1. Open an issue explaining the user problem (or link an existing one).
2. Keep each change focused on one improvement.
3. Add or update a deterministic local test.
4. Run `npm run check` and `npm test` with Chromium installed.
5. Update both README files when behavior changes.
6. Open a pull request and describe checks run and remaining limits.

Do not submit fabricated activity, copied proprietary assets or changes made solely to earn achievement badges. Never test external sites without permission. Maintainers review before merge; automation does not merge itself.
